# Locs by Ben

A responsive website I built for **Locs by Ben**, a locs specialist offering mobile hair services around Kiserian, Kenya.

## 🌐 Live Demo

[View the live website](https://gee-126.github.io/Ben-s-Locs/)

## About the Project

This was a real-world frontend project where I practiced taking a business idea and turning it into a working website.

The website includes information about the services, previous work, testimonials, and contact details, with WhatsApp as the main booking option.

## ✨ Features

* Responsive navigation with a mobile menu
* Hero, services, gallery, about, and contact sections
* Testimonials
* WhatsApp booking button
* Social media links
* Responsive layouts
* Hover effects and transitions

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Git & GitHub
* GitHub Pages

## 📚 What I Practiced

Through this project, I worked with:

* HTML page structure
* CSS Flexbox and Grid
* Responsive design and media queries
* JavaScript DOM manipulation
* Event listeners
* `getElementById()` and `querySelector()`
* `classList.toggle()` and `classList.contains()`
* Git and GitHub
* Debugging
* Website deployment

One challenge I ran into was getting the mobile navigation to work. My JavaScript selectors didn't initially match my HTML structure, so I had to debug the connection between the HTML, CSS, and JavaScript. That helped me understand the DOM much better.

## 🎯 Why I Built It

I'm learning frontend development by building actual projects instead of only following tutorials. This project gave me practice taking a website from the initial structure all the way to a deployed, usable product.
